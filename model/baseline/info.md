# model/baseline - Files Not Included

The baseline model files are not included in this repository due to size limitations.

## What belongs here

Trained policy and value network weights for the **baseline agent** — the final variant of the engine.

Each model is saved at 3, 10, and 20 epochs across 3 pipeline iterations.

## How to get the files

Download them from the [Releases]([../../../releases](https://github.com/Kostas0030/Lightweight-Chess-Agent-for-Aggressive-Play/releases)) page of this repository and place them in this folder.
