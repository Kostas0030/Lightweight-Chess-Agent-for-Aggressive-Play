# database — Files Not Included

The database files are not included in this repository due to size limitations.

## What belongs here

PGN game files used for supervised learning. The engine trains the policy and value networks on positions extracted from these games, producing ~3.5 million board state samples.

## How to get the files

The dataset is taken from:

[https://database.nikonoel.fr/](https://database.nikonoel.fr/)

After downloading, place the `.pgn` files in this folder.
